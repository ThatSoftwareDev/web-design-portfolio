# Web Design Portfolio

Concept designs and an interactive prototype for small-business and SaaS landing pages.
The focus is on clear page structure, a distinct visual identity per industry, and documented
interaction states.

> **Note:** All businesses, names, addresses, phone numbers, prices and testimonials in this
> repository are **fictional** and were created for demonstration purposes only.

### Tierheim Wiesengrund
Landing page for an animal shelter. I decided to display a warm green and cream palette, serif headlines with an italic accent.
Sections: hero with live stock count, key figures, animal cards (dogs, cats, small animals) with breed/age/arrival data, a five-step adoption process, ways to help without adopting (sponsorship,donations in kind, volunteering) and a contact form with opening hours.

### Tischlerei Voss
Landing page for a family-run carpentry business. Wood tones on a warm off-white and dark charcoal, serif headlines. 
Sections: hero with "currently open" status, key figures, services grid, workshop story with a quote, selected projects, customer testimonials and a project inquiry form.

### SCHWARZ&GOLD
Dark landing page for a hair studio. Elegant black and gold palette, high-contrast serif headline with an italic accent word. 
Sections: hero with booking CTA, key figures, a price list styled as a menu ("Die Karte"), testimonials, opening hours with address and a closing call-to-action.

### Kontur (interactive prototype)
Mid-fidelity, annotated prototype for a SaaS landing page. Each interactive component is numbered
and linked to a spec table (default, hover, active, focus, error, success, with duration and easing).
Live in the browser:

- CTA button states (switchable preview)
- Feature card hover
- Monthly/yearly pricing toggle that updates all plan cards
- Testimonial slider
- Lead form with email validation, error shake, loading and success state
- Global transition rules (150–200 ms micro, 300 ms standard, 300–500 ms panel changes)
